# RetinoScan

n this project, we successfully developed a Convolutional
 Neural Network (CNN)-based model for the classification of
 retinal diseases using fundus images. The model was trained
 and evaluated using the Retinal Fundus Multi-Disease Image
 Dataset (RFMiD) sourced from AKGGEL. By incorporating
 image augmentation techniques, we enhanced the model's
 ability to generalize and minimized the risk of overfitting.
 The project covered the complete machine learning
 workflow—from data preprocessing and model training to
 performance evaluation and visualization of predictions.
 The results demonstrate the model's potential in aiding
 early diagnosis of retinal diseases, contributing
 meaningfully to the field of automated medical image
 analysis
